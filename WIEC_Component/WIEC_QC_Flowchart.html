WIEC QC Test Flow

What happens from launching run_wiec_component.py to the summary report. Next to each stage is every file it uses, the function called, and what that file is doing at that point. Traced from main (commit 0cdcf86c plus uncommitted edits), 15 Oct 2026.

File categories (the readme's, plus files outside WIEC_Component/)
Top script / test script Test helper General helper Instrument driver / link Config, state, slides Runs on the WIB Output file
1

Launch

The operator double-clicks the desktop shortcut. With no flags the menu opens; --all / --items run straight through; --list, --suggest, --preflight and --shutdown do one thing and exit.

File → what it does here
  • wiec-test.desktopOpens a shell in the repo root and runs the top script. The root matters: the CAEN driver loads its .so from there.
  • run_wiec_component.pymain reads the flags and decides which mode to run.
  • config.jsonLoaded once here; every later step reads its settings from it.
2

Preflight checks

Make sure the PC and the instruments are ready before anything is powered.

Preflight OK? No → “Continue? [y/N]”; N exits. Yes → menu.
File → what it does here
  • preflight.pycheck_environment checks Python packages and config, and pings each instrument IP. print_report shows the results. print_suggestions prints new-user notes on a first run.
  • .wiec_component_state.jsonRead by preflight.is_first_run to decide whether to show the notes; rewritten at exit by preflight.mark_run.
  • config.jsonSupplies the instrument IPs that get pinged.
  • WIEC_utils.pyTitle banner and PASS/FAIL colours on the report; ask for the y/N prompt.
3

Menu

The operator picks what to do:

  • item numbers, or f for all five in order → stage 4
  • n new-user notes · p redo preflight · s shut instruments down
  • q save and quit → stage 6
File → what it does here
  • run_wiec_component.pyinteractive loops on the menu; print_items lists the items with their status so far.
  • WIEC_utils.pyColours the option letters (teal = operator action) and the status column.
  • preflight.pyOptions n and p rerun print_suggestions and check_environment.
  • session.pyOption s: shutdown_only turns every supply off without ending the session.
4

Set up the session

Happens once, before the first item runs.

  • Overview slide, then “find the serial” slide; WIEC serial typed twice.
  • Session created, legacy spreadsheet row opened, run folder made, session log started.
  • Operator name, then the “set up the test stand” slide.
File → what it does here
  • run_wiec_component.pybuild_session runs these steps in order.
  • WIEC_utils.pymake_instruction_popup checks a window can open; show_slides shows each slide; confirm_input_ask asks for the serial and name.
  • popups.pyavailable says if a window can open here (desktop, tkinter, PIL); image_path finds the PNG for a slide number.
  • GUI/pop_window.pyDraws the slide window with its Confirm button.
  • GUI/wiec_pngs/The slide images, made from Hardware_Instructions.odp by GUI/export_wiec_slides.sh.
  • record_results.pyfile_name_safe cleans the serial for file names; run_path makes runs/<date-time>_<serial>/.
  • session.pyTestSession loads config and holds the instruments, results paths and datastore for every later step.
  • spreadsheet.pyResultSpreadsheet.open (called by TestSession) opens the legacy results spreadsheet row and stamps the date.
  • output_log.pystart copies everything printed from here on into session_log.txt.
5

Run each item

Each item's run(session) returns pass or fail. If it errors or the operator presses Ctrl-C, everything is powered down and the item is marked INTERRUPTED. In a full run, a failed item does not stop the next.

Files every item uses
  • run_wiec_component.pyrun_item calls the item and catches errors and Ctrl-C.
  • session.pyOpens each instrument the first time an item asks for it (session.caen, .keysight, .rigol0, .rigol1, .pl506); record stores the item's result; emergency_shutoff on errors.
  • record_results.pymeasure grades each reading against its min/max and adds it to the measurements.
  • WIEC_utils.pyProgress bars during waits (run_with_bar, countdown_sleep), prompts, PASS/FAIL colours.

Fan Test fan_test · ~1 min

Power the fans at nominal voltage, wait fan_wait, then record the fan supply V/I and each fan's RD frequency.

  • fan_test.pyrun → measure runs the test and grades it.
  • rigol_dp832a.pyRigol #0 powers the fans; Rigol #1 powers the RD pull-up. Reads back supply V and I.
  • keysight_daq970a.pyinitialize_fan / measure_fan read the RD frequency of each fan.

Fan PWM Sweep fan_pwm_sweep · ~3 min

Step the fan voltage from min to max, measure at each point, then grade the fans against each other by correlation and RMSE.

  • fan_pwm_sweep.pyRuns the sweep, saves the CSV and PNG curves, grades the curves.
  • fan_test.pymeasure is reused for the reading at each voltage step.
  • rigol_dp832a.pySets each sweep voltage, then restores the nominal one.
  • keysight_daq970a.pyReads the fan frequencies at each step (through fan_test.measure).

Heater Test heater_test · ~1 min

Measure the four heating-element resistances unpowered, then power them and record the RTD temperature rise after heat_wait.

  • heater_test.pyrun does both halves and grades them.
  • keysight_daq970a.pymeasure_resistance for the elements; measure_rtd for the temperature before and after.
  • rigol_dp832a.pyRigol #0 powers the heater supply and heater switch; reads back their V and I.

HV Test hv_test

  1. HV warning slide; operator types hv_warning_phrase.
  2. Relay pull-ups on.
  3. For each channel group (all at once or one at a time, per simultaneous_test), four phases, each ramped up and back down: +2000 V open, +20 V into 10 kΩ, −2000 V open, −20 V into 10 kΩ.
  4. V/I logged, τ fitted on the open phases, resistance checked, plots saved.
  • hv_test.pyacknowledge_hv_warning, then test_channels runs the phases; record_hv_data logs V/I to CSV; _evaluate grades.
  • caen_r8033dm_wrapper.pySets the voltage, ramps channels on and off, reads V and I on all 16 channels.
  • caen_r8033dm.pyLow-level CAEN library calls under the wrapper (loads the .so).
  • keysight_daq970a.pyset_relay picks positive/negative and open/10 kΩ for each phase.
  • rigol_dp832a.pyRigol #1 powers the two HV relay pull-ups.
  • analysis.pyhv_curve_fit fits a·e−bt+c for τ; make_plot / make_term_plot draw the PNGs.
  • output_log.pylog writes each channel's full results to the session log only.

WIB/FEMB wiec_wib_qc · ~70 min

Move one WIB (or wib_boards_available WIBs) through the selected slots. At each slot, check the WIB's link through the WIEC, then run an FEMB checkout through it.

  • wiec_wib_qc.pyrun drives the whole item; run_batch handles one batch of slots.
  • ptc_power.pyFan-interlocked 48 V power for the PTC.
  • wib_setup.pyZynq login and the per-slot WIB check.
  • femb_checkout.pyRuns the FEMB checkout on the WIB over ssh and grades it on the PC.
  • wiec_femb_chk.pyThe script copied to and run on the WIB.
  • wiec_serial.pySerial console to the Zynq: WIB power and sensor reads.
a
Operator picks the WIB slots (all, or a list typed twice). Slots are split into batches. FEMB sets and enabled tests are read. “Check the FEMBs” slide.
  • wiec_wib_qc.pyprompt_wiec_test_info asks for slots; make_batches splits them.
  • femb_checkout.pyget_femb_sets / get_femb_tests read and check which FEMBs and tests to use.
  • config.jsonwib_test_slots, wib_boards_available, wiec_femb_sets, wiec_femb_tests.
b
PTC power-up: fans on and confirmed spinning, then 48 V on. If this fails, the item fails.
  • ptc_power.pypower_up → ensure_fans_on → turn_on_pl506.
  • rigol_dp832a.pyPowers the fans (Rigol #0) and RD pull-up (Rigol #1).
  • keysight_daq970a.pyConfirms every fan is above fan_osc_freq before 48 V is allowed.
  • pl506.pysafe_turn_on_channel brings the PTC's 48 V up within the V/I limits.
  • wiec_serial.pystore_current_usb_ports notes the USB ports present before the Zynq powers, so its new port can be found.
c
Log in to the Zynq (PetaLinux) over USB serial.
  • wib_setup.pylogin_zynq handles failures and returns the serial handle.
  • wiec_serial.pylogin finds the new /dev/ttyUSB* port and logs in as root.
for each batch
d
“Put the WIB in slot N” slide for each slot. Power the batch's WIBs and read their sensor addresses.
  • wiec_wib_qc.pyrun_batch shows the slides (falls back to “press Enter”).
  • wiec_serial.pypower_wib powers the slots; run_ecat_soft_timeout_then_i2cdetect scans I²C; sensors_addr reads each WIB's sensors.
for each WIB in the batch
e
Slot check: expected I²C address present and WIB IP answers ping. Fail → recorded, next WIB.
  • wib_setup.pycheck_slot → validate_wib_i2c_outputs compares I²C addresses; ping_wib pings the expected IP.
f
FEMB checkout through this slot:
  1. Pick the FEMB set for this slot (prompt to move it if needed).
  2. Copy the checkout script to the WIB.
  3. First attempt only: set the WIB clock, run wib_startup.py.
  4. Run the checkout over ssh, settings sent as JSON.
On the WIB
Powers the FEMBs, drops any with no current, no I²C or unsafe current, runs the enabled BNL warm tests, powers the FEMBs off, prints one WIEC_RESULT_JSON line.
Back on the PC: parse the result, copy BNL's plots back, grade.
  • femb_checkout.pyfemb_set_for_slot picks the set; copy_script_to_wib scp's the script; prepare_wib sets the clock and starts the WIB; run_assembly_checkout runs it over ssh; parse_result reads the JSON; fetch_report copies plots back; grade checks against wiec_femb_limits; fembs_off makes sure FEMBs are off.
  • wiec_femb_chk.pyRuns on the WIB: power, I²C and safety checks, then the BNL tests. Only measures; grading is on the PC.
  • wib_startup.pyBNL's WIB start-up: timing and I²C phase setup. Once per power-up.
  • wib_cfgs.pyBNL's WIB/FEMB configuration class, used by wiec_femb_chk.py.
  • components/assembly_function.pyBNL's analysis for the ADC data tests (noise, pulse); writes plots to CHK/Report.
  • femb_checkout_wibN.txtFull WIB output, saved under raw/femb_checkout/.
g
FEMB checks pass? No → continue, retry (back to f, no second wib_startup.py) or abort (skip remaining WIBs).
The final attempt is written to the measurements.
  • wiec_wib_qc.pyprompt_after_failure asks c/r/a.
  • femb_checkout.pyprint_femb_results shows the checks; record_measurements writes the final attempt.
  • record_results.pymeasure stores each FEMB check with its slot and FEMB serial.
h
Batch WIBs powered off; “take the WIB out of slot N” slide for each slot.
  • wiec_serial.pypower_wib with every slot set to off.
  • WIEC_utils.pyshow_slides for the removal slide.
i
Always, even after abort or an error: close serial, 48 V off, then fans off.
  • wiec_serial.pyclose_serial closes the Zynq console.
  • ptc_power.pypower_down: PL506 channel and main off first, then the fans.
  • pl506.pychannel_off, main_off.
6

Finish and write results

Runs on q, at the end of --all/--items, or after Ctrl-C or an error. Each write is wrapped so one failure does not stop the others.

The “take down the test stand” slide shows only after a normal finish. After Ctrl-C or an error it is skipped so the operator can retry.

File → what it does here
  • run_wiec_component.pyfinish runs these steps in order.
  • session.pyemergency_shutoff turns every supply off; finalize writes the overall result; save_datastore writes run.json; close_instruments.
  • caen, rigol, pl506, keysightEach told to turn off by emergency_shutoff; relays reset to 0.
  • iseg_mpod.pyUsed only here: turns off the HV channels of the MPOD slot.
  • spreadsheet.pywrite_overall puts the overall PASS/FAIL in the legacy spreadsheet.
  • record_results.pywrite_measurements → measurements.csv; write_qc_sheet → wiec_qc.xlsx.
  • wiec_report.pywrite_report builds summary.html from run.json and plots/.
  • output_log.pystop closes session_log.txt.
  • preflight.pymark_run updates the state file so the next run is not a “first run”.
7

Output: the run folder

Names come from config.json.

WIEC_Component_Results/runs/<YYYY-MM-DD_HH-MM-SS>_<serial>/
├── run.json
├── measurements.csv
├── wiec_qc.xlsx
├── summary.html
├── session_log.txt
├── plots/<test>/
└── raw/
File → what it holds · written by
  • run.jsonThe whole session datastore · session.save_datastore
  • measurements.csvOne row per reading, with limits and result · record_results.write_measurements
  • wiec_qc.xlsxOne QC row: PASS / FAIL / INTERRUPTED per item · record_results.write_qc_sheet
  • summary.htmlSelf-contained report with plots embedded · wiec_report.write_report
  • session_log.txtEverything printed, colour codes removed · output_log
  • plots/PNGs per item, including BNL's FEMB plots · each item, femb_checkout.fetch_report
  • raw/HV V/I CSVs, fan sweep CSV, WIB output · each item

Other ways in

  • cli.pyrun_single_item runs one item alone, e.g. python3 -m WIEC_Component.heater_test config.json name. It builds its own session and powers down on exit. No slides.
  • wiec_report.pyRun directly to rebuild a summary: python3 -m WIEC_Component.wiec_report [run folder | --all].
  • session.pyshutdown_only, from --shutdown or menu s: CAEN, MPOD slot, PL506, both Rigols off, relays reset.
